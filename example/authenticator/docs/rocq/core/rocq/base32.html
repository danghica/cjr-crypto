decode_values

cjr.authenticator.base32.decode_values

AI-generated explanation

decode_values processes a list of integers, accumulating each value by multiplying the accumulator by 32 and adding the value, while increasing a bit count by five. When the count reaches at least eight, it emits the integer quotient by 2 raised to the excess bit count and continues with the remainder and reduced count; otherwise it continues accumulating. It returns the emitted integers in order and the final accumulator, returning an empty list and the current accumulator when the input is empty. Recursion consumes one list element per step. This suggests unpacking Base32 values into bytes, but the declaration supplies no bounds on the inputs or initial state that would guarantee valid byte outputs.
